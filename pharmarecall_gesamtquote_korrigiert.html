GitHub-Synchronisierung

Verbinde GitHub einmal mit deinem Token. Danach kannst du ihn mit einem eigenen Passwort verschlüsselt im Browser speichern.

Bei dauerhaftem Login wird zusätzlich ein Geräteschlüssel im Browser gespeichert. Wer Zugriff auf dein entsperrtes Gerät und dessen Browserdaten hat, kann dann auch GitHub verwenden. Ohne Haken ist dein Passwort bei jedem neuen Besuch nötig.

Die GitHub-Datendatei ist in einem öffentlichen Repository öffentlich lesbar. Das Passwort schützt nur den Zugriffstoken.
